🌐 LangConnect

Connect with people. Learn languages. Share cultures.
LangConnect is a simple language-learning and language-exchange platform where users can create profiles, 
select their native and learning languages, and connect with other people who want to learn new languages.

✨ Features
* User Registration: Create an account with your personal details.
* User Login: Log in using your registered email and password.
* Language Selection: Choose your native language and the language you want to learn.
* Learning Level: Select your current language proficiency level.
* Language Partners: Find other users who are interested in language exchange.
* Contact Page: Provides a way to get in touch.
* Simple Interface: Easy-to-use navigation and a consistent design.
